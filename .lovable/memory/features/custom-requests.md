## Custom Request Workflow

- Customer submits a bid (1–500 BT) with a description
- Creator can accept, decline, or counter-offer (new price + message)
- Customer sees counter-offers in their dashboard and can accept or decline
- Accepted requests move to payment step
- After payment, creator has **42 hours** to deliver
- Requests expire after **14 days** if no action
- Requests are private — customers only see their own, creators only see requests to them
- Split: 85% creator / 15% platform on the base amount
- Customer pays base + $1 DTT fee + $4 card processing cover
- Creators can reuse request videos in their library to earn more
